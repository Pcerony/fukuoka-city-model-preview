# 福冈地图：道路优先 73 块打印版

采用已确认的 v13 外缘防窄尾分割，独立保留，不覆盖旧版 56 块地图。
当前状态：73 块闭合单实体 STL、四份已切片原生 3MF 完成数字验收；未实物验证。

## 编号

A-H 从北向南；分块按横向带的最大重叠面积归行，每行按中心 X 从西向东依次编号。
不限制每行数量，不重复、不加后缀。C 行是 C1-C10，其余七行各 1-9，共 73 个唯一编号。
网页 `preview/index.html`、背面凹刻、STL 名称、盘序清单共用编号。原始 R 编号仅供追溯。
装配位置见 `assembly_overview.png`；完整包围框 1494 x 1316 mm。

## 打印规格

- A1 mini，180 x 180 mm 平台，一盘一块，分块包围框约 178 mm。
- XY 不缩放，沿用前版半高映射，最薄河床 0.4 mm。
- 背面编号和北向箭头凹刻 0.2 mm，字高 10 mm，是前版的两倍；整段轮廓避河并检查上方材料。
- PLA Basic，0.4 mm 喷嘴，首层及层高 0.2 mm，5% 稀疏填充。
- 墙、顶底层、温度沿用原版配置；无支撑、无 brim、无 skirt。
- 四份原生 Bambu Studio 多盘 3MF，盘数 20 / 20 / 20 / 13；打开为完整项目，不只导入几何。
- 多盘文件不等于连续自动打印。每盘取件后需选择下一盘。未发送打印任务。

最终全套 105 项单元测试通过，日志在 `diagnostics/unit_tests_final.log`。
`geometry_audit.json` 核验 73 块和 170 组接边；`batch_audit.json` 核验 73 盘嵌入模型、参数、实际凹刻路径、校验码和原生重载。切片总览见 `slicer_previews.png`。
最低表面 0.400000006 mm，凹刻上方最薄 0.663619 mm，文字/箭头离河至少 3.102615 mm；最大接边高度差 0.002751 mm。

所有道路、河流、缓冲后的建筑及分块轮廓在全局坐标采用共用的 0.001 mm 精度网格，然后再平移到局部，不再局部二次吸附。
道路先全局避水、简化，再局部截取。地形、道路、建筑在 double 精度中融合后，用共用的最终分块裁切器切割，避免分开裁切和过早 float32 转换造成非流形接触。
背面刀具从 Z=-0.01 到 Z=0.2，实际穿过底面，不形成内部封闭空腔。
优先原 Boolean，仅在实际 STL 回读不通过时尝试 0.0001 mm 简化；必须闭合、正向、单实体。

裁切侧壁必须使整个 XY 三角投影位于真实裁切边的 0.00003 mm 容差带内，不能只看顶点；文字侧壁还必须连接 Z=0 与 Z=0.2。
地形最低表面仍须至少 0.4 mm，数值底部薄片面积总量仍限 0.0001 mm2。
实际凹刻顶面、底部开放性、整个文字和箭头上方材料、接边另行核验。接缝参考精度与裁切器一致，移除零宽毛刺，不放过实际缺侧或内部高度差。

实际量化后的分块集合并非数学上严格零缝零叠。审计单列缺口、越界、重叠和孔洞；要求缺口/越界各小于 0.01 mm2、累计重叠小于 0.05 mm2，且这些差异不能存在半径 0.0015 mm 的实心内核。不得把数值容差说成严格无缝。

## 风险与来源

数字验收不代表实物强度或打印成功。0.4 mm 河床仍只有两层；先确认实际耗材、平台附着和薄底强度。
G9 河岸只有约 0.04894 mm2 的平坦河床碎片，离岸不足一个喷嘴宽，不能据此断言两层切片覆盖。报告明确标为 `bank_detail_only_not_verified`；几何厚度通过，但这处细节在切片中可能消失。
部分普通建筑仍被分割，并未保证所有具名地标完整。新增地标候选没有补建。建筑调查年为 2022。
沿用 PLA Basic 温度；打印前核对实际耗材及平台，关闭传统延时摄影。改变喷嘴、brim 或参数后需重新检查范围和切片。
原生切片仍报告平台温度偏高和传统延时摄影不受支持；警告完整保留，未擅自改变旧版温度设置。
